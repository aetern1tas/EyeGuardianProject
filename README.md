## Описание

**EyeGuardian Project** — это десктопное приложение, которое отслеживает состояние глаз пользователя через веб-камеру и предупреждает о признаках усталости. Система использует алгоритм **EAR (Eye Aspect Ratio)** для анализа закрытия век и фиксирует данные в локальной базе для последующего анализа.

### Для кого этот проект:
- Родители для контроля усталости глаз детей при учёбе за компьютером
- Студенты и исследователи в области компьютерного зрения
- Офисные работники для профилактики синдрома компьютерного зрения

## Возможности

| Функция | Описание |
|---------|----------|
| Детекция лица в реальном времени | Использует MediaPipe Face Mesh для отслеживания 468 лицевых ориентиров |
| Расчёт EAR | Вычисление Eye Aspect Ratio для обоих глаз по 6 ключевым точкам |
| Детекция усталости | Автоматическое определение усталости при низком EAR в течение нескольких кадров |
| Логирование сессий | Сохранение показателей EAR и уровня усталости в базу данных |
| Режим перерыва | Встроенный таймер перерыва с возможностью паузы и возобновления |

## Конфигурация

Файл `config.py` позволяет настроить параметры без изменения кода:

```python
class Config:
    # Путь к базе данных
    SQLALCHEMY_DATABASE_URI = 'sqlite:///eyeguard.db'
    
    # Отключение отслеживания модификаций (оптимизация)
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    
    # Порог EAR для детекции усталости (0.0–1.0)
    EAR_THRESHOLD = 0.21
    
    # Количество кадров подряд для срабатывания тревоги
    CONSECUTIVE_FRAMES = 3
```

### Настройка порога EAR
- **Высокое значение** (0.25+) — более чувствительная детекция, возможны ложные срабатывания
- **Низкое значение** (0.18–) — менее чувствительная, пропускает лёгкую усталость
- **Рекомендуемое**: 0.20–0.22 для большинства пользователей

## База данных

### Схема данных

```
User (1) ──────< (N) Session (1) ──────< (N) EyeRecord
   │                                        │
   └────────────< (N) EyeRecord >───────────┘
```

#### Модели

**User** (Пользователь)
- `id` — уникальный идентификатор
- `username` — имя пользователя
- `created_at` — дата создания аккаунта

**Session** (Сессия)
- `id` — уникальный идентификатор сессии
- `user_id` — ссылка на пользователя
- `start_time` — время начала сессии
- `end_time` — время завершения
- `total_minutes` — общая продолжительность в минутах
- `break_count` — количество перерывов

**EyeRecord** (Запись о состоянии глаз)
- `id` — уникальный идентификатор записи
- `session_id` — ссылка на сессию
- `user_id` — ссылка на пользователя
- `timestamp` — время записи
- `ear_score` — значение EAR (0.0–1.0)
- `fatigue_level` — уровень усталости (low/high/unknown)

## Алгоритм работы

### Расчёт EAR (Eye Aspect Ratio)

```
EAR = (||p2−p6|| + ||p3−p5||) / (2 × ||p1−p4||)

где:
  p1, p4 — горизонтальные углы глаза
  p2, p3, p5, p6 — вертикальные точки верхнего и нижнего века
```

#### Ключевые точки для каждого глаза:
```python
LEFT_EYE = [33, 160, 158, 133, 153, 144]   # MediaPipe landmark indices
RIGHT_EYE = [362, 385, 387, 263, 373, 380]
```

### Логика детекции усталости

```
1. Получить кадр с камеры
2. Обнаружить лицо и извлечь 468 ориентиров (MediaPipe)
3. Вычислить EAR для левого и правого глаза
4. Усреднить значения: avg_ear = (left + right) / 2
5. Если avg_ear < threshold:
       увеличить счётчик последовательных кадров
   Иначе:
       сбросить счётчик
6. Если счётчик >= max_consecutive_frames:
       установить fatigue_level = HIGH
   Иначе:
       fatigue_level = LOW
7. Сохранить запись в базу данных
8. Отобразить результат на экране
```

## Родителям: Контроль усталости глаз ребёнка

> **EyeGuardian Project** помогает вам заботиться о зрении ребёнка во время учёбы и игр за компьютером.

### Как использовать для контроля ребёнка

1. **Запускайте перед уроками**
   - Попросите ребёнка нажать **S** для начала сессии
   - Приложение будет отслеживать усталость в фоновом режиме

2. **Анализируйте статистику**
   - Проверьте базу данных `eyeguard.db` после занятий
   - Посмотрите, сколько времени ребёнок работал с признаками усталости
   - Обратите внимание на количество перерывов

3. **Настройте напоминания о перерывах**
   - Объясните ребёнку, что при нажатии **B** начинается перерыв
   - Рекомендуйте делать перерыв каждые 20–30 минут

### Рекомендации для родителей

 **Делайте перерывы каждые 20 минут** (правило 20-20-20: каждые 20 минут смотрите на объект в 20 футах в течение 20 секунд)

 **Контролируйте освещение** — экран не должен быть ярче окружающего света

 **Следите за позой** — расстояние от глаз до экрана 50–70 см

 **Поощряйте моргание** — напоминайте ребёнку чаще моргать

##  Устранение неполадок

### Камера не открывается
```bash
# Проверьте доступ к камере в настройках ОС
# Убедитесь, что камера не используется другим приложением
```

### Ошибка загрузки MediaPipe
```bash
# Переустановите зависимости
pip uninstall mediapipe opencv-python
pip install mediapipe==0.10.0 opencv-python==4.8.0
```

### База данных не создаётся
```bash
# Удалите старый файл БД и запустите заново
rm eyeguard.db
python app.py
```

### Приложение зависает при запуске
```bash
# Запустите с флагом отладки для просмотра логов
python -u app.py
```
