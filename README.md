## Описание

**EyeGuardian Project** — это десктопное приложение, которое отслеживает состояние глаз пользователя через веб-камеру и предупреждает о признаках усталости. Система использует новый API MediaPipe **FaceLandmarker** для детекции 468 лицевых ориентиров и алгоритм **EAR (Eye Aspect Ratio)** для анализа закрытия век. Все данные фиксируются в локальной базе SQLite для последующего анализа.

### Для кого этот проект:
- Родители для контроля усталости глаз детей при учёбе за компьютером
- Студенты и исследователи в области компьютерного зрения
- Офисные работники для профилактики синдрома компьютерного зрения

## Установка

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/yourusername/eyeguardianproject.git
cd eyeguardianproject
```

**2. Создайте виртуальное окружение**

```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux
# или
venv\Scripts\activate     # Windows
```

**3. Установите зависимости**

```bash
pip install -r requirements.txt
```

Список зависимостей:
- `flask` — веб-фреймворк (используется для контекста приложения)
- `flask_sqlalchemy` — ORM для работы с базой данных
- `opencv-python` — работа с камерой и изображениями
- `mediapipe==0.10.13` — компьютерное зрение (FaceLandmarker)
- `numpy` — математические операции

**4. Убедитесь, что модель MediaPipe присутствует**

Файл `face_landmarker.task` должен находиться в корне проекта (рядом с `app.py`). Если его нет, скачайте с официального репозитория MediaPipe:

```bash
wget https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
```

**5. Запустите приложение**

```bash
python app.py
```

При первом запуске автоматически:
- Создастся база данных `eyeguard.db`
- Создастся пользователь `default_user`

## Использование

### Состояния приложения

Приложение работает в трёх состояниях:

| Состояние | Описание |
|-----------|----------|
| `welcome` | Начальный экран. Ожидание начала сессии |
| `active` | Активная сессия. Камера включена, детекция усталости работает |
| `break` | Перерыв. Таймер показывает длительность отдыха |

### Управление в приложении

| Клавиша | Действие | Режим |
|---------|----------|-------|
| `S` | Начать сессию | Welcome |
| `B` | Начать перерыв (увеличивает счётчик перерывов в БД) | Active |
| `R` | Возобновить сессию | Break |
| `Q` | Выйти из приложения и завершить сессию | Любой |

### Отображаемая информация

В режиме `active` на экране отображается:
- **Статус усталости**: "Low fatigue" (зелёный) или "HIGH FATIGUE - TAKE A BREAK!" (красный)
- **Текущее значение EAR**: числовое значение с точностью до 3 знаков
- **Сообщение**: "Face not detected" — если лицо не обнаружено

## Конфигурация

Файл `config.py` позволяет настроить параметры без изменения кода:

```python
class Config:
    # Путь к базе данных (через BASE_DIR)
    SQLALCHEMY_DATABASE_URI = 'sqlite:///' + os.path.join(BASE_DIR, 'eyeguard.db')
    
    # Отключение отслеживания модификаций (оптимизация)
    SQLALCHEMY_TRACK_MODIFICATIONS = False
    
    # Порог EAR для детекции усталости (0.0–1.0)
    EAR_THRESHOLD = 0.21
    
    # Количество кадров подряд для срабатывания тревоги
    CONSECUTIVE_FRAMES = 3
```

### Настройка порога EAR
- **Высокое значение** (0.25+) — более чувствительная детекция, возможны ложные срабатывания
- **Низкое значение** (0.18–) — менее чувствительная, пропускает лёгкую усталость
- **Рекомендуемое**: 0.20–0.22 для большинства пользователей

## База данных

### Схема данных

```
User (1) ──────< (N) Session (1) ──────< (N) EyeRecord
   │                                        │
   └────────────< (N) EyeRecord >───────────┘
```

#### Модели

**User** (Пользователь)
- `id` — уникальный идентификатор
- `username` — имя пользователя
- `created_at` — дата создания аккаунта

**Session** (Сессия)
- `id` — уникальный идентификатор сессии
- `user_id` — ссылка на пользователя
- `start_time` — время начала сессии
- `end_time` — время завершения
- `total_minutes` — общая продолжительность в минутах
- `break_count` — количество перерывов (увеличивается при нажатии `B`)

**EyeRecord** (Запись о состоянии глаз)
- `id` — уникальный идентификатор записи
- `session_id` — ссылка на сессию
- `user_id` — ссылка на пользователя
- `timestamp` — время записи
- `ear_score` — значение EAR (0.0–1.0)
- `fatigue_level` — уровень усталости (Enum: LOW / HIGH / UNKNOWN)

## Алгоритм работы

### Инициализация MediaPipe FaceLandmarker

При создании объекта `FatigueDetector` происходит:
1. Загрузка модели `face_landmarker.task` из корня проекта
2. Настройка параметров: `num_faces=1`, `min_face_detection_confidence=0.5`
3. Создание экземпляра `FaceLandmarker` через новый API MediaPipe

### Расчёт EAR (Eye Aspect Ratio)

```
EAR = (||p2−p6|| + ||p3−p5||) / (2 × ||p1−p4||)

где:
  p1, p4 — горизонтальные углы глаза
  p2, p3, p5, p6 — вертикальные точки верхнего и нижнего века
```

#### Ключевые точки для каждого глаза:
```python
LEFT_EYE = [33, 160, 158, 133, 153, 144]   # MediaPipe landmark indices
RIGHT_EYE = [362, 385, 387, 263, 373, 380]
```

### Логика детекции усталости

```
1. Получить кадр с камеры (cv2.VideoCapture)
2. Конвертировать BGR → RGB
3. Создать mp.Image и передать в FaceLandmarker.detect()
4. Если лицо не обнаружено — вернуть UNKNOWN
5. Извлечь landmarks[0] (первое лицо)
6. Вычислить EAR для левого и правого глаза
7. Усреднить значения: avg_ear = (left + right) / 2
8. Если avg_ear < threshold:
       увеличить счётчик consecutive_frames
   Иначе:
       сбросить счётчик
9. Если consecutive_frames >= max_consecutive_frames:
       установить fatigue_level = HIGH
   Иначе:
       fatigue_level = LOW
10. Сохранить запись в базу данных (EyeRecord)
11. Отобразить результат на экране через cv2.imshow()
```

## Родителям: Контроль усталости глаз ребёнка

> **EyeGuardian Project** помогает вам заботиться о зрении ребёнка во время учёбы и игр за компьютером.

### Как использовать для контроля ребёнка

1. **Запускайте перед уроками**
   - Запустите `python app.py`
   - Попросите ребёнка нажать **S** для начала сессии
   - Приложение будет отслеживать усталость в фоновом режиме

2. **Анализируйте статистику**
   - Откройте базу данных `eyeguard.db` через любой SQLite-клиент (например, DB Browser for SQLite)
   - Посмотрите таблицу `eye_record` — сколько записей с `fatigue_level = HIGH`
   - Проверьте таблицу `session` — количество перерывов (`break_count`)

3. **Настройте напоминания о перерывах**
   - Объясните ребёнку, что при нажатии **B** начинается перерыв
   - Рекомендуйте делать перерыв каждые 20–30 минут
   - Счётчик перерывов автоматически сохраняется в БД

### Рекомендации для родителей

- Делайте перерывы каждые 20 минут (правило 20-20-20: каждые 20 минут смотрите на объект в 20 футах в течение 20 секунд)
- Контролируйте освещение — экран не должен быть ярче окружающего света
- Следите за позой — расстояние от глаз до экрана 50–70 см
- Поощряйте моргание — напоминайте ребёнку чаще моргать

## Устранение неполадок

### Камера не открывается
- Проверьте доступ к камере в настройках ОС
- Убедитесь, что камера не используется другим приложением
- В логах появится: `[ERROR] Camera not found`

### Модель не найдена
- Ошибка: `FileNotFoundError: Модель не найдена по пути: ...`
- Убедитесь, что файл `face_landmarker.task` находится в корне проекта
- Скачайте модель: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

### Ошибка загрузки MediaPipe
```bash
# Переустановите зависимости с нужными версиями
pip uninstall mediapipe opencv-python
pip install mediapipe==0.10.13 opencv-python
```

### База данных не создаётся
```bash
# Удалите старый файл БД и запустите заново
rm eyeguard.db
python app.py
# Автоматически создастся новая БД и пользователь default_user
```

### Лицо не детектируется
- Проверьте освещение — оно должно быть достаточным
- Убедитесь, что лицо находится в кадре
- В логах: `Face not detected`
- Можно понизить `min_face_detection_confidence` в `detector.py` (по умолчанию 0.5)

# Запустите с флагом отладки для просмотра логов
